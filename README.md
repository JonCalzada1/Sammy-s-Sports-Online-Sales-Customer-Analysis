# Sammy's Sports Online Sales & Customer Analysis

**Tools:** SQL and Tableau  
**Role:** Data Analyst  
**Focus Areas:** Sales trends, customer segmentation, product performance, regional insights

## Overview

This project analyzes the online sales data of Sammy’s Sports to uncover key trends and business opportunities.

I cleaned and joined multiple tables using SQL, and built an interactive Tableau dashboard that tracks sales by product, month, and U.S. state.

## Data Preparation (SQL)

Key steps:
- Removed duplicates, standardized formats, and handled NULL values
- Joined `sales`, `customers`, and `products` tables
- Aggregated data for Tableau visualization

See full SQL script: [`SQL/data_preparation.sql`](SQL/data_preparation.sql)
